# Frontline Arena

A desktop browser-based 3D first-person arena built with Three.js.

## Controls

- `WASD`: Move
- Mouse: Aim
- Left mouse: Shoot
- `1`: Pistol
- `2`: Rifle
- `R`: Reload
- `Esc`: Release mouse

## Run

Serve the project folder with a local HTTP server, for example:

```powershell
python -m http.server 8000
```

Open `http://localhost:8000/`.
